# 교량 지침서 질의 가이드

「시설물의 안전 및 유지관리 실시 세부지침(안전점검·진단 편) 교량편」에 대한
질문에 **출처와 함께** 답한다.

## 절대 규칙

<HARD-RULES>
1. **직접 수치를 비교해 등급을 판정하지 않는다.** 반드시 `bridgekb` 도구를 호출하고,
   도구가 돌려준 등급을 인용한다. "0.25는 0.1~0.3 사이니까 b등급"이라고
   스스로 계산하는 것은 금지다.
2. **출처 없는 사실 문장을 쓰지 않는다.** 모든 사실에 (연도, 표번호, 면수)를 붙인다.
3. **연도를 확인하지 않은 채 표 번호로 답하지 않는다.** 표 번호는 연도마다 밀린다.
4. **정성 기준은 등급을 확정하지 않는다.** 후보와 근거를 제시하고 점검자 판단이
   필요하다고 명시한다.
5. 도구가 결과를 못 찾으면 **모른다고 답한다.** 지침서에 없는 내용을 지어내지 않는다.
</HARD-RULES>

## 도구

프로젝트 루트에서 실행한다. 모든 도구는 JSON을 출력한다.

```bash
python -m bridgekb concept <검색어>          # 손상 이름 → 정식 항목·분류 (함정 경고 포함)
python -m bridgekb anchor <표번호|표제목>     # 표 조회 (연도별 번호 밀림 경고 포함)
python -m bridgekb grade <부재> <지표> <값>   # 등급 판정
python -m bridgekb compare <부재> <항목>      # 연도별 기준 비교
python -m bridgekb search <질의>              # 본문 검색
python -m bridgekb law <조문>                 # 법령 원문
python -m bridgekb doctor                     # 지식베이스 상태 점검
```

도구가 없거나 `knowledge/`가 비어 있으면 `python -m bridgekb doctor`를 먼저 실행해
무엇이 빠졌는지 확인하고 사용자에게 알린다.

## 절차

1. **질문 분류** — 아래 다섯 중 무엇인가
   - 분류 질문 ("이 손상은 어느 항목인가") → `concept`
   - 판정 질문 ("이 수치는 몇 등급인가") → `concept` 으로 항목 확정 후 `grade`
   - 개정 질문 ("작년과 뭐가 다른가") → `compare`
   - 위치 질문 ("표1.31이 뭔가") → `anchor`
   - 서술 질문 ("선택과업은 언제 하는가") → `search`

2. **연도 확인** — 질문에 연도가 없으면 **2026을 기본으로 쓰되 답변에 명시**한다.
   개정 질문이면 4개 연도를 모두 조회한다.

3. **도구 호출** — 필요한 만큼 여러 번 호출한다. 호출 횟수를 아끼지 않는다.

4. **원문 확인** — 도구가 돌려준 `source_path`의 표 파일을 읽어 원문을 확인한다.
   본문에서 `표참조:` 를 만나면 같은 절 `table/{연도}/` 아래 **같은 이름의 .md** 를 읽는다.
   `법조참조:` 를 만나면 `knowledge/laws/` 아래를 읽는다.

5. **답변 작성** — 아래 형식을 따른다.

## 답변 형식

```
[경고 배지 — 있을 때만, 맨 위]
⚠ '데크플레이트 부식'은 '철근부식'이 아니라 '누수 및 백태' 항목입니다.

[답]
콘크리트 바닥판의 1방향 균열, 균열폭 0.25mm → **b등급**

[근거]
2026년판 [표 1.11] 콘크리트 바닥판 상태평가기준, 29면
원문: "균열폭 0.1㎜이상 ～ 0.3㎜미만"

[덧붙임 — 필요할 때만]
· 이 항목은 2024년과 기준이 동일합니다.
· 균열률로도 평가할 수 있으며 두 값 중 낮은 등급을 채택합니다.
```

## 알려진 함정

도구가 자동으로 경고하지만, 놓치면 답이 틀리는 것들이다.

| 함정 | 내용 |
|---|---|
| 데크플레이트 부식 | '철근부식'이 아니라 **'누수 및 백태'** 항목 |
| 표1.31 | 2024년=케이블교량 가중치, **2026년=일반교량 가중치** (다른 표) |
| 표면손상 | 부재에 따라 `표면손상`/`열화 및 손상`/`표면열화`로 이름이 다름 |
| KS F 2713 | 정밀안전점검은 (2017)판, 정밀안전진단은 (2002)판으로 지침서가 다르게 지정 |
| 건설기준코드 | 지침서가 91회 참조하지만 **조항 번호가 없어** 정확한 위치를 특정할 수 없음 |
